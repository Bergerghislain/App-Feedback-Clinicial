# Comment obtenir les PDF sur Overleaf (Mirakl + RATP)

Tu n’as **pas besoin** de télécharger les PDF du dépôt : copie les fichiers `.tex` dans Overleaf.

## Procédure (2 minutes par document)

1. Va sur [https://www.overleaf.com](https://www.overleaf.com) → **New Project** → **Blank Project**
2. Supprime le contenu de `main.tex`
3. Ouvre l’un des fichiers ci-dessous dans le dépôt GitHub, **copie tout**, colle dans `main.tex`
4. Clique **Recompile**
5. Menu **PDF** → **Download PDF**
