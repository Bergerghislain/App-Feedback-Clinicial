# Overleaf — 4 CV (Akeneo / ChapsVision / MARSO / Adelean)

## Comment coller dans Overleaf (30 secondes)

1. Aller sur [overleaf.com](https://www.overleaf.com) → **New Project** → **Blank Project**
2. Ouvrir `main.tex`, **tout sélectionner**, coller le contenu du fichier `.tex` ci-dessous
3. Compiler en **pdfLaTeX** → Download PDF
4. Renommer le projet Overleaf (ex. `CV Akeneo Studios`)

Un projet Overleaf **par offre** (ne mélange pas les 4 fichiers dans le même `main.tex`).
